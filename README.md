## 🌟 Overview

The **Kuberan Dharma App** brings the timeless wisdom of India's sacred scriptures into everyday modern life through atomic, bite-sized **"Dharma Cards"** designed for clarity and daily spiritual growth.

Instead of dense, archaic volumes, readers experience concise cards featuring authentic Devanagari text, phonetic IAST transliteration, audio chanting, and our **3-Layer Understanding Model**.

---

## 🏛️ The 5 Sacred Corpuses

1. **Bhagavad Gita (श्रीमद्भगवद्गीता):** Complete 18 chapters and flagship philosophical verses on Karma Yoga, detachment, and self-mastery.
2. **Valmiki Ramayana (श्रीमद्वाल्मीकिरामायणम्):** Pivotal episodes illuminating Maryada (righteous conduct), truth, and selfless service.
3. **Mahabharata (महाभारतम्):** Ethical crossroads, moral dilemmas, and the famous Yaksha Prashna dialogue.
4. **Vedas & Upanishads (वेदाः उपनिषदश्च):** Primordial peace chants (Taittiriya Shanti Mantras) and contemplative wisdom.
5. **Puranas & Parables (पुराणानि):** Transformative parables of unwavering devotion (Bhakti) and spiritual fortitude.

## 💡 The 3-Layer Insight Engine

Every Dharma Card is structured across three distinct layers of comprehension:

| Layer | Sanskrit Term | Purpose |
|:---|:---|:---|
| **Layer 1: Literal Translation** | *Shabdartha* | Word-by-word meaning and direct, transparent translation. |
| **Layer 2: Spiritual Essence** | *Tatparya* | The underlying metaphysical truth and timeless philosophical core. |
| **Layer 3: Modern Life Practice** | *Vyavahara* | Practical takeaway for stress, leadership, relationships, and decision-making. |

## ⚡ Key Capabilities

- **100% Offline-First & Zero Cloud API Costs:** Powered by local curated static data and client-side `minisearch`. Zero external API keys needed.
- **Audio Chanting & Syllable Guide:** Built-in chanting playback, speed adjustment ($0.75\times, 1.0\times, 1.25\times$), loop repetition counters ($1, 3, 9, 21, 108$), and interactive Sanskrit syllable breakdowns.
- **Curated & Personal Stashes:** Save wisdom cards into curated packs (*Krishna's 7 Mental Models*, *Ramayana Leadership Principles*, *Moral Dilemmas of the Mahabharata*, *Vedic Peace Invocations*) or organize your own personal collections in local browser storage.
- **Streak & Habit Tracker:** Built-in midnight-safe daily learning streak counter.
- **Google Stitch Design Standard:** Implements the official Kuberan brand tokens (Imperial Maroon `#6B1D2F`, Antique Temple Gold `#C5A059`, Deep Gold `#8F6E28`, Warm Pearl Ivory `#FAFAF7`, Charcoal Slate `#1C1917`) strictly adhering to WCAG 2.2 AAA accessibility.

## 🚀 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Jee1VK/kuberan-dharma-app.git
   cd kuberan-dharma-app
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Run test suite:**
   ```bash
   npm test
   ```

5. **Build for production export:**
   ```bash
   npm run build
   ```
